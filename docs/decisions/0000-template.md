## Context

What forces are at play — technical, product, operational — that prompted this
decision? Keep it tight: the reader should understand *why* the question exists
without needing the full project history.

## Decision

The choice, in one sentence. Then a short paragraph if more detail helps.

## Consequences

What becomes easier, harder, or fixed as a result. Include both wanted and
unwanted consequences. If this decision creates follow-up work, link the ADR
or issue that tracks it.

so future-you doesn't relitigate it.
